# StackerPulse ⚡ + SeedScan 🛡️

**Автор:** `UBro-dev` · **Лицензия:** MIT (Copyright (c) 2026 UBro-dev) · [English version](README.md)

Настольный помощник для [Stacker News](https://stacker.news) на Rust
(Tauri v2) для Windows и Linux. Берёт живые данные SN (по желанию через Tor),
показывает, сколько территории зарабатывают на самом деле, проверяет посты на
утечку секретов перед публикацией, чистит ссылки и ведёт учёт баунти. Без
телеметрии, без демо-цифр и без обращений туда, куда вы не просили.

> Статус: v3.1.0. Проверено на Linux (release-сборка, 85 тестов, настоящее окно).
> Каждый релиз собирается и тестируется в CI на Windows, Linux и macOS.
> Все GraphQL-запросы проверены по схеме из исходников
> `stackernews/stacker.news`.

## Что умеет

- **SeedScan — офлайн-сканер секретов.** Ищет в выбранных папках и в
  черновике поста:
  - BIP39 seed-фразы (12–24 слова) — **с проверкой контрольной суммы**
  - xprv/yprv/zprv/tprv — с проверкой Base58Check
  - WIF-ключи — с проверкой Base58Check
  - Nostr `nsec1…` — с проверкой Bech32
  - ключи Solana: файлы `id.json` и экспорт в base58, с проверкой ed25519
    (публичная половина должна совпадать с секретной)
  - Lightning NWC URI с `secret=`
  - пути, выдающие имя пользователя (`C:\Users\<имя>\`, `/home/<имя>/`)

  Только чтение, без сети, все находки маскируются
  (`abandon ***** about (12 words)`). Обычный английский текст не
  срабатывает: контрольные суммы проверяются. Есть консольная версия:
  `cargo run --release --bin seedscan-cli -- <папки>`.

- **OpSec-проверка перед публикацией.** Предупреждает прямо при наборе
  поста (в том числе e-mail и публичный IP) и умеет вычистить пути и
  ключи из черновика.

- **Очистка ссылок** (SN issue #2664). Убирает трекеры (`utm_*`, `fbclid`,
  `gclid`, `s`/`t` только на x.com, `si` только на YouTube/Spotify…), не
  ломая нужные параметры вроде таймкода YouTube, и может переписать
  x.com → xcancel / Nitter, reddit → Redlib, medium → scribe.rip на ваш
  инстанс.

- **Живая лента.** Горячее / новое / топ по любой территории и периоду,
  загрузка с SN по кнопке, локальные фильтры, поиск, закладки с заметками и
  тегами, экспорт в CSV. Пока вы ничего не загрузили, лента пуста.

- **Баунти.** Активные баунти самого SN, награды за PR из GitHub и ваши
  собственные задачи — в одном трекере.

- **Реальная экономика территорий.** Статистика самого SN (`topSubs`):
  сколько основатель фактически получил за период, запы, число постов и
  окупает ли это тариф (50k sats в месяц, 500k в год или 3M разово). Доход
  приводится к 30 дням, чтобы сравнивать с ценой тарифа; для разовых тарифов
  показано, за сколько месяцев цена отбивается.

- **Статистика стакера.** Публичная статистика любого @ника: собрано и
  потрачено за день, неделю, месяц, год и всё время, посты, серии. Если
  человек скрыл статистику в SN, приложение так и пишет, а не угадывает.

- **Студия постов** с реальными ценами постов в территориях,
  **GraphQL-песочница**, **интерфейс RU/EN** и вкладка **«Настройки и
  приватность»** (Tor-прокси и просмотр исходников Rust, вшитых в приложение).

## Приватность

- **Allowlist в Rust.** Клиент SN подключается только к `stacker.news` и его
  официальному onion
  `snsnsnya6h3ot563f3p566wuhfoklkg5f62hokdlaqzcaub3gf4xlxyd.onion` — при
  первом запросе и на каждом редиректе (не больше 3).
- **Tor через `socks5h://`**: DNS и `.onion` резолвятся внутри Tor.
  Приложение само находит Tor на порту 9150 (Tor Browser) или 9050 (служба
  tor). Если `.onion` не отвечает, запрос один раз повторяется к
  `stacker.news` через тот же Tor (отключается в настройках); тогда и
  ссылки копируются как `stacker.news`, потому что onion-ссылка тоже не
  откроется.
- **Режим Airgap** вообще не даёт создать HTTP-клиент.
- **GitHub — только по согласию.** Радар PR-баунти обращается к
  `api.github.com`, только если вы это включили, только по кнопке, без
  токена, без редиректов и только к двум фиксированным путям одного
  репозитория. Без Tor приложение сначала спрашивает: GitHub увидит ваш IP.
- **Никакого удалённого кода.** Chart.js и Tailwind вшиты; строгий CSP
  разрешает только локальные скрипты и Tauri IPC — сам интерфейс в сеть
  выйти не может.
- **Ссылки копируются, а не открываются**, чтобы ничего не ушло через
  системный браузер мимо Tor. С включённым Tor ссылки SN копируются как
  `.onion`.
- **Без `Referer`, cookies и `Accept-Language`.** По умолчанию не
  отправляется и `User-Agent`; это само по себе заметно, поэтому можно
  включить UA как у Tor Browser. GitHub всегда получает этот UA: без него он
  отклоняет запросы.

## Установка

Скачайте со страницы **Releases** репозитория:

| Система | Файл |
|---|---|
| Windows 10/11 | `StackerPulse_<версия>_x64_en-US.msi` или `…_x64-setup.exe` |
| Linux | `StackerPulse_<версия>_amd64.AppImage` или `…_amd64.deb` |
| macOS 10.15+ (Apple Silicon и Intel) | `StackerPulse_<версия>_universal.dmg` |
| Только консольный сканер | `seedscan-cli-<система>.tar.gz` / `.zip` |

**Проверьте файл, прежде чем запускать.** К каждому релизу приложены
`SHA256SUMS.txt` и подписанная аттестация сборки: она доказывает, что файл
собран GitHub Actions из этого репозитория и после этого не менялся:

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing        # Linux
shasum -a 256 -c SHA256SUMS.txt --ignore-missing    # macOS
gh attestation verify <файл> --repo UBro-dev/stacker-pulse
```

В Windows: `Get-FileHash <файл> -Algorithm SHA256` и сравните с
`SHA256SUMS.txt`.

**Установщики не подписаны сертификатом разработчика.** Microsoft и Apple
выдают такие сертификаты только на проверенное настоящее имя, а проект
ведётся под псевдонимом. Вместо подписи — аттестация выше. При первом запуске
будет одно предупреждение:

- **Windows** (SmartScreen, «Система Windows защитила ваш компьютер»):
  *Подробнее* → *Выполнить в любом случае*. Если нет WebView2 (старые
  Windows 10), установщик скачает его с сайта Microsoft; в Windows 11 он уже
  есть.
- **macOS**: перетащите программу в *Программы* и откройте один раз. Когда
  macOS скажет, что не может проверить разработчика, откройте *Системные
  настройки → Конфиденциальность и безопасность* и нажмите *Всё равно
  открыть* (в macOS 14 и старше работает и Control-клик → *Открыть*). Или в
  Терминале: `xattr -dr com.apple.quarantine /Applications/StackerPulse.app`
- **Linux AppImage**: `chmod +x StackerPulse_*.AppImage`, затем запустите.

## Сборка и запуск

Нужен Rust (stable). На Linux ещё `libwebkit2gtk-4.1-dev`.

```bash
cd src-tauri
cargo test --release     # 85 тестов
cargo run --release      # запустить приложение
```

Установщики (`.msi` / `.exe`, `.AppImage` / `.deb`, `.dmg`):

```bash
cargo install tauri-cli --version "^2"
./build_linux.sh          # Linux
.\build_windows.ps1       # Windows (PowerShell)
./build_macos.sh          # macOS, универсальная сборка
```

Скрипты сборки вычищают из бинарников путь к вашей домашней папке (иначе
rustc вшил бы `C:\Users\<ваше имя>\…` сотни раз) и останавливаются, если он
всё же остался. Если собираетесь кому-то отдавать сборку, собирайте через
них, а не голым `cargo tauri build`.

Релизы собирает CI, а не человек: тег `vX.Y.Z`, совпадающий с версией в
`src-tauri/Cargo.toml`, запускает `.github/workflows/release.yml`. Он
прогоняет тесты на всех трёх системах, собирает все установщики и CLI,
прикладывает их к **черновику** релиза вместе с контрольными суммами и
аттестациями и ждёт, пока вы нажмёте *Publish*.

После изменения CSS-классов в интерфейсе пересоберите Tailwind:

```bash
npx tailwindcss@3.4.17 -c tools/tailwind.config.js -i tools/tailwind.input.css -o ui/vendor/tailwind.css --minify
```

## Ограничения

- SeedScan знает только перечисленные форматы. Архивы, PDF и офисные файлы
  он не читает, и «ничего не найдено» не означает, что всё чисто.
- Цифры по территориям и стакерам — те, что отдаёт SN. Долю основателя
  можно менять для каждой территории, поэтому берётся фактический доход, а
  не формула.
- Награды за PR — верхняя граница; Stacker News платит на своё усмотрение.
