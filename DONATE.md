## Before you send · Перед отправкой

- **Send only the token on the network shown.** USDC must go over Solana and
  USDT over Tron; another token or network loses the funds.
- **Check the address after pasting it.** Clipboard malware swaps crypto
  addresses. Compare the first and last six characters with this page.
- **Verify the source.** The same addresses are built into the app. This
  file lives in [github.com/UBro-dev/stacker-pulse](https://github.com/UBro-dev/stacker-pulse),
  whose commits are signed. If an address you were given anywhere else
  differs from this file, do not use it.

- **Отправляйте только указанный токен в указанной сети.** USDC — только в
  Solana, USDT — только в Tron; другой токен или сеть — деньги потеряются.
- **Проверьте адрес после вставки.** Вирусы-клипперы подменяют адреса в буфере
  обмена. Сверьте первые и последние шесть символов с этой страницей.
- **Проверьте источник.** Те же адреса вшиты в приложение. Этот файл лежит в
  репозитории с подписанными коммитами. Если где-то вам дали другой адрес, не
  используйте его.
